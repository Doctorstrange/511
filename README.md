# 511

# QRISK in chronic disease — systematic review and meta-analysis

Analysis code and data for a systematic review and random-effects meta-analysis of
the discriminative performance of the QRISK cardiovascular risk algorithm in
chronic-disease populations.

**PROSPERO registration:** [CRD420251230395](https://www.crd.york.ac.uk/prospero/display_record.php?RecordID=1230395)
**Module:** DASC511, MSc Health Data Science, University of Liverpool

---

## What this repository contains

Everything needed to reproduce the meta-analysis from the extracted study data:
the extraction sheet, one R Markdown document containing the full analysis, the
knitted output, and the intermediate datasets the analysis writes out.

```
├── data/
│   └── meta_analysis_index8.xlsx      # data extraction sheet (34 validation arms)
├── output/
│   ├── df_all.xlsx                    # all 34 arms, parsed and cleaned
│   ├── df_primary.xlsx                # 19 arms in the primary discrimination pool
│   └── df_primary-logit.xlsx          # primary pool with logit transform and SE
├── pdf/
│   └── QRISK_meta_s1.pdf              # knitted analysis, all output and figures
├── QRISK_meta_analysis_final4.Rmd     # the analysis
└── README.md
```

`output/` is generated by the `.Rmd` and is committed so the intermediate datasets
can be inspected without running anything.

## Reproducing the analysis

```r
# from the repository root
rmarkdown::render("QRISK_meta_analysis_final1.Rmd")
```

The document reads `data/meta_analysis_index5.xlsx` relative to its own location,
so no paths need editing.

## Analysis summary

| | |
|---|---|
| Studies included in review | 24 |
| Validation arms | 34 |
| Arms in primary pool | 19 (from 14 unique studies) |
| Disease groups | 6 |
| Participants / events | 959,237 / ~81,977 |

**Pooled c-statistic** 0.7433 (95% CI 0.7089–0.7749)
**95% prediction interval** 0.5912–0.8529
**Heterogeneity** *Q* = 436.96, df = 18, *p* < 0.0001; *I*² = 95.9%; τ² = 0.1026

Discrimination was pooled on the logit scale following Debray et al. (2019),
using restricted maximum likelihood with a Hartung–Knapp adjustment. The
hand-coded pipeline (`meta::metagen`) is cross-validated against the reference
implementation (`metamisc::valmeta`); the two agree on the summary estimate to
four decimal places.

## How the primary pool was derived

All 34 arms are retained in `df_all`. The 19-arm primary pool applies four
filters in sequence:

1. `Include == 1` — met review eligibility criteria
2. `Metanalysis == 1` — drops 3 duplicate QRISK2 arms from cohorts also scored
   with QRISK3 (retained for the version subgroup and paired comparison)
3. `Dscrimination != "Heller's K"` — drops 3 CARMA arms reporting Gönen–Heller's
   K, which is not on a common scale with the ROC AUC or Harrell's *c*
4. `Outcome_type == "Appropriate"` — drops 9 arms validating against surrogate
   endpoints or a modified outcome definition

The excluded arms are not discarded: they inform the QRISK-version, discrimination-metric
and surrogate-outcome analyses.

## Data notes

Points where the extracted data required judgement, recorded here so the
decisions are auditable.

**Confidence intervals.** The `Confidence_interval` column records provenance for
every arm: `Reported` (taken from the source), `Approximated` (reconstructed from
the c-statistic and the event and non-event counts using the Hanley & McNeil
(1982) variance formula), or `Pooled` (sex-specific Harrell's *c* combined by
fixed-effect inverse-variance pooling).

**Gönen–Heller's K arms.** Llorca et al. report K rather than an ROC AUC. The
Hanley & McNeil formula is derived for the binary-outcome AUC and is not valid
for K, so no interval is given for these three arms and they are excluded from
all pooled analyses.

**Alemao et al.** report outcome events only as an incidence rate (1.78 per 100
patient-years among 12,747 participants over a mean 6.0 years). The count used in
the meta-regression is derived as rate × person-time (≈1,361 events). This value
enters only the meta-regression on cohort-level covariates; the pooled
discrimination estimate is computed from reported c-statistics and their
confidence intervals and is unaffected.

## Data provenance

All data were extracted from published reports of QRISK validation studies. No
individual participant data were obtained or analysed, and no ethical approval
was required. Each row of the extraction sheet corresponds to a published
validation arm; full citations are given in the dissertation reference list.
